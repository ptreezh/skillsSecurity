# 常见错误与解决方案

## 上传阶段

### 错误：缺少 Skill 英文描述（description_en）
**原因**：SKILL.md frontmatter 缺少 `description_en` 字段
**解决**：添加 `description_en: "English description"` 后重新打包

### 错误：技能名称 "xxx" 已被占用
**原因**：`name:` 字段与平台已有技能冲突
**解决**：修改为唯一名称，如 `agentskills-xxx`

### 错误：解析失败
**原因**：zip 包结构不符合规范
**解决**：确保根目录有 SKILL.md，目录结构正确

## 表单阶段

### 错误：请至少选择 1 个分类
**原因**：市场展示分类未选择
**解决**：点击 combobox，选择至少一个分类

### 错误：请选择类目
**原因**：服务类目未选择
**解决**：点击「添加」或「请选择」，在树形选择器中选择子类目

### 错误：请完善必填信息
**原因**：表单有未填写的必填项
**解决**：检查所有带 `*` 的字段是否已填写

## 提交阶段

### 错误：提交失败，请重试
**原因**：网络问题或表单校验失败
**解决**：检查网络，确认所有必填项已填写

## 自动化问题

### bsk click 返回 "target element has no visible geometry"
**原因**：元素被弹窗遮挡或不在视口内
**解决**：
1. 先滚动到元素可见位置
2. 关闭遮挡的弹窗
3. 使用键盘操作代替

### bsnapshot 返回 "selector did not match"
**原因**：文件输入框被隐藏
**解决**：先用 JS 显示 input，再 upload
