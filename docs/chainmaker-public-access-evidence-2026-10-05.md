# ChainMaker 官方公网接入证据（2026-10-05）

> 用途：为计划 R25 / D9 提供可复核的一手证据，取代「记录于本次会话」这类不可追溯引用。
> 纪律：只记录**直接观测到的事实**；凡未观测到的，一律显式标注为「未证实」，不得由「未找到」推出「不存在」。

---

## 1. 观测方法与边界

| 项 | 值|
|---|---|
| 观测日期 | 2026-10-05 |
| 观测手段 | HTTPS 抓取公开页面（`webfetch`） |
| 观测对象 | `https://chainmaker.org.cn/` 及其首页返回的HTML |
| 未使用 | 任何需登录的开发者后台、SDK 仓库内网文档、ChainMaker 官方客服渠道 |

**本次观测不能回答的问题**：ChainMaker 官方**是否**在某个未公开或需申请授权的地址提供公网主网接入。抓取只覆盖公开入口。

## 3. 证据边界（防止推理越界）

**可以说的：**
- C1–C3 说明：**公开官网首页**在观测时点未提供可直接引用的公网接入文档。
- C4–C5 说明：**本仓库**当前跑在私有链上，链访问不经公网。

**不可以说的：**
- 「ChainMaker 没有公网主网」——C1 只是首页外壳，未覆盖文档站、SDK 仓库、公告、申请通道等入口。**未找到 ≠ 不存在。**
- 「私有链导致上架不可信」——已由计划 rev.10 撤回该推论；上架信任主体是 WorkBuddy 平台，不是链。
