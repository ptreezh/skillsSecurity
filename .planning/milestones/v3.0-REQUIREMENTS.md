# v3.0 需求：WorkBuddy 技能化发布
> Milestone: v3.0 — 将 AgentSkills 系统能力分解为 WorkBuddy 可消费的 SKILL + 专家智能体 + 连接器，并上架 open.workbuddy.cn

## 背景
- v2.0 已完结：公网前端 → 后端 API → ChainMaker chain1 全链路打通
- 当前系统具备：技能审计、链上注册、声誉查询、排行榜、指纹生成等核心能力
- 目标：把这些能力包装成 WorkBuddy 生态可安装、可调用、可搜索的标准化资产

## 核心目标
1. 把 AgentSkills 后端能力拆解为 7 个独立 SKILL
2. 实现 1 个专家智能体（AgentSkills Team），支持端到端编排
3. 实现 2 个连接器（Backend MCP + Chain MCP），隔离后端细节
4. 通过 open.workbuddy.cn 审核并成功上架

## 需求清单

### REQ-31：技能包结构标准化
- 所有 SKILL 遵循 WorkBuddy 规范：SKILL.md + references/ + scripts/ + templates/
- SKILL.md frontmatter 必填字段完整：name, display_name, description, category, version, author
- 所有脚本具备独立运行能力，不依赖前端/浏览器环境

### REQ-32：核心技能开发（7 个）
| 技能 | 职责 | 输入 | 输出 | 触发词 |
|------|------|------|------|--------|
| skill-auditor | 审计 .SKILL.md 合规性 | SKILL.md 内容 | JSON 审计报告 | 审计技能, skill audit, 安全扫描 |
| skill-publisher | 打包为 WorkBuddy 标准 .zip | 技能目录 | .skill.zip + manifest.yaml | 发布技能, 打包 skill |
| skill-registry | 调用后端 /api/upload → /api/chain | skillId, creator | txHash, skillId | 注册技能, 上链 |
| reputation-analyst | 查询声誉/排行榜/统计 | address 或 limit | reputation JSON | 查询声誉, 排行榜 |
| skill-browser | 浏览/搜索技能列表 | page, pageSize, query | 技能列表 JSON | 搜索技能, 技能列表 |
| fingerprint-verifier | 计算文件指纹 | 文件路径或内容 | fingerprint hash | 计算指纹, 验证技能 |
| risk-classifier | 评估风险等级 | SKILL.md 内容 | RiskLevel + 因素列表 | 风险评估, 风险分类 |

### REQ-33：专家智能体编排
- 定义 AgentSkills Team：1 个 Team Lead + 7 个 Member
- Team Lead 工作流：审计 → 风险评估 → 指纹 → 打包 → 注册 → 声誉查询 → 整合报告
- 支持用户通过自然语言触发端到端流程

### REQ-34：连接器实现
- AgentSkills Backend MCP Connector：封装 /api/upload, /api/chain, /api/skills, /api/reputation, /api/leaderboard, /api/stats
- AgentSkills Chain Connector：封装链上交互（通过后端网关间接调用）
- 连接器支持 Bearer Token 认证，支持本地 demo 模式（无需真实后端）

### REQ-35：本地端到端验证
- 7 个 SKILL 可独立安装、独立调用
- Team Lead 可完整编排端到端流程
- 连接器可对接本地后端（localhost:10001）
- 所有脚本具备独立测试用例

### REQ-36：open.workbuddy.cn 上架
- 完成实名认证
- 打包并提交至少 1 个 SKILL + AgentSkills Team 专家智能体
- 通过安全扫描 → AI 审核 → 人工抽检
- 成功上架并可被 WorkBuddy 用户搜索安装

## 非目标（Out of Scope）
- 不涉及代币发行或价值交换
- 不修改 AgentSkills 后端核心逻辑，只做调用适配
- 不重复造前端（WorkBuddy 客户端负责 UI）
- 不覆盖所有 7 个 SKILL 的上架（Phase 1 先上架 3 个核心 SKILL + Team）

## 假设与依赖
- WorkBuddy 开放平台（open.workbuddy.cn）审核规则稳定
- AgentSkills 后端 API（localhost:10001）可访问
- ChainMaker chain1 后端网关可用（cmc 容器运行）
- 审核期间可提供 demo 模式数据，不依赖真实链上数据

## 成功标准
1. 7 个 SKILL 全部可通过 WorkBuddy 本地加载并调用
2. AgentSkills Team 专家智能体可完成端到端技能发布流程
3. 至少 1 个 SKILL 通过 open.workbuddy.cn 审核并上架
4. 用户可在 WorkBuddy 市场搜索到「AgentSkills」相关技能
